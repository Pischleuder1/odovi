# Odovi 0.2.0 release notes

Release version: `0.2.0`

Install the immutable Compose asset attached to the published GitHub Release.
Its web and worker image digests identify the exact accepted builds; source
checkouts and candidate tags are not a substitute for that release asset.

## Highlights

- Odovi is the public and technical product identity across the application
  and self-hosted stack.
- The journey archive, planning, analysis, export, and administration surfaces
  carry a discoverable version and build identity.
- The release stack validates configuration before starting long-running
  services and reads TeslaMate through the documented read-only boundary.

## Supported runtime

- Application runtime: Node.js 22, included in the web and worker images.
- Database: PostgreSQL 17.
- Orchestration: Docker Engine with Docker Compose v2.
- TeslaMate: 4.0.1 through 4.2.0. The endpoint versions are exercised with
  revision-verified schema fixtures and every synchronization query path.
- Images: `linux/amd64` and `linux/arm64` from one source commit.

## Tested platforms

The automated release checks cover:

- `linux/amd64` on GitHub-hosted Ubuntu: complete disposable-stack acceptance.
- `linux/arm64` through QEMU BuildKit: image build and metadata validation.

The exact published images also passed native Raspberry Pi 5 runtime acceptance.
Upgrade from the pinned public v0.1.1 source, backup restoration and rollback
were verified separately with ARM64 Linux containers in OrbStack. The attached
`release-candidate.json` records the automated gates; `acceptance-summary.json`
records the additional runtime and upgrade checks without raw logs or test data.

## Known limitations

- Native ARM64 hardware acceptance covers Raspberry Pi 5; other NAS and ARM64
  hardware combinations have not been individually tested.
- TeslaMate 4.0.2 through 4.1.x are bounded by the tested 4.0.1 and 4.2.0
  endpoints; they do not each have a dedicated fixture.
- One vehicle per installation is the current supported focus.
- An existing supported TeslaMate database is required and is not bundled.

The accepted Release Candidate record is the authoritative source for the
source commit, exact web and worker digests, and automated gate results.
